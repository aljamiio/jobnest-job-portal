
# JobNest - Job & Internship Portal

JobNest is a full-stack job and internship portal built using the MERN stack.

## Features

- User Authentication
- Role-based Access Control
- Job Search and Filtering
- Job Posting and Management
- Job Application Tracking
- Employer Dashboard
- Admin Dashboard

## Technology Stack

- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS

## Project Status

Currently under development.

## Running the Frontend

Navigate to the client directory:

```bash
cd client
```

Install dependencies (first time only):

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL in your browser:

```text
http://localhost:5173/
```

### Stopping the Development Server

Press `Ctrl + C` in the terminal to stop the server.

### Restarting the Development Server

Run the following command again from the client directory:

```bash
npm run dev
```
